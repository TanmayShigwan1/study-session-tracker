# 📚 Study Session Tracker

A simple full-stack study session tracker built with **Java, Spring Boot, REST APIs, HTML, CSS, and JavaScript**.

The project allows users to create, view, update, delete, and filter study sessions while displaying basic study statistics.

---

## 🚀 Features

- View all study sessions
- View a session by ID
- Add a new study session
- Update an existing session
- Delete a study session
- Automatically generate session IDs
- Calculate total study duration
- Find the longest study session
- Filter sessions by subject
- Filter sessions by status
- Dashboard with session statistics
- Frontend connected to Spring Boot REST API
